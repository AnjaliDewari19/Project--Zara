##
🌸 ZARA COLLECTION

Your Style, Your Choice! ✨

ZARA COLLECTION is a modern and responsive fashion website built with React.js. 
It showcases different categories of ethnic wear such as Short Kurtis, Long Kurtis, Layered Gowns, and Farsi Suits.

The website allows users to explore collections, view products, check price ranges, read customer reviews, and contact the store through WhatsApp.
